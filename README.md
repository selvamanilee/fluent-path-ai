# FluentPath AI — English Communication Coach

**Learn. Practice. Speak. Improve.**

A personalized English coach for Tamil-speaking learners, taking them from absolute beginner to professional (IT workplace) communication. It has daily 30-minute sessions, Read / Write / Speak / Lesson modules, vocabulary with Tamil meanings, spaced revision, four 100-mark exams with evidence-based level progression, and an installable PWA.

| Part | Path | Stack |
|---|---|---|
| Web app (PWA) | `apps/web` | Angular 22, standalone components, signals, SCSS, service worker |
| API | `apps/api` | Next.js 16 route handlers, TypeScript, zod, PostgreSQL (`pg`), JWT |
| Agent engine | `services/agent` | Python, FastAPI, LangGraph orchestrator, LangChain (Ollama) |
| Database | `db/migrations` | PostgreSQL 16 |

## Run locally

Prerequisites: Node 22, Python 3.12+, PostgreSQL 16. Ollama is optional.

```bash
createdb fluentpath   # role/password: see apps/api/.env.example
```

```bash
cd apps/api && cp .env.example .env.local && npm install && npm run migrate && npm run seed && npm run dev
```

```bash
cd services/agent && python3 -m venv .venv && .venv/bin/pip install -r requirements.txt && AGENT_SERVICE_TOKEN=change-me .venv/bin/uvicorn app.main:app --port 8000
```

```bash
cd apps/web && npm install && npm start   # http://localhost:4200 (proxies /api → :3000)
```

For AI feedback, install [Ollama](https://ollama.com) and run `ollama pull llama3.1:8b`. Alternatively, set `MODEL_PROVIDER=openai` plus `OPENAI_API_KEY` for any OpenAI-compatible endpoint. **Without a model, the app still works fully**: open answers are checked by a rule-based grammar checker, and the UI labels that feedback "Rule-based check" rather than "AI tutor feedback".

To test the production PWA build (service worker on), run `npm run build && npm run serve:dist` in `apps/web`.

## Tests

```bash
cd apps/api && npm test                            # unit + integration (needs DB fluentpath_test)
```

```bash
cd services/agent && .venv/bin/python -m pytest -q
```

```bash
cd apps/web && npm run e2e                         # Playwright; needs the 3 services + serve:dist
```

For e2e, start the API with `RATE_LIMIT_AUTH=200 RATE_LIMIT_DEFAULT=2000`, because every test user shares one IP.

## Honest limitations
* Pronunciation is **not scored from audio**. No speech-assessment service is integrated yet. The app gives TTS playback, browser speech-to-text transcripts and syllable guidance, and says so in the UI.
* Seed content covers Level 1 fully and Level 2 partly. Grammar lessons without seed content are generated by the agent when a model is configured; otherwise the app says the lesson is unavailable.
* iOS Safari was tested only through Chromium device emulation, not on a real iPhone. See `docs/07-ios-checklist.md`.
